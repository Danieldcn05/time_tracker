# ⏰ Time Tracker Linux
Time Tracker es una aplicación desarrollada en Python 🐍 que rastrea el tiempo de uso de aplicaciones seleccionadas. Utiliza psutil para monitorear procesos en tiempo real y almacena los datos en una base de datos SQLite 🗄️ para su análisis posterior. La interfaz gráfica, creada con Tkinter 🎨, permite gestionar fácilmente las aplicaciones a rastrear.

## ✨ Características
🕒 Rastreo en tiempo real del inicio y cierre de aplicaciones específicas.

📊 Almacenamiento de datos en una base de datos SQLite para futuras consultas y análisis.

💻 Interfaz gráfica sencilla e intuitiva creada con Tkinter.

⚙️ Configuración personalizada para añadir o eliminar aplicaciones a rastrear.

🔄 Ejecución en segundo plano para no interrumpir la experiencia del usuario.

🖥️ Sistema operativo compatible: Linux



## 📥 Instalación
Clona este repositorio:

```bash
git clone https://github.com/Danieldcn05/time_tracker
cd time-tracker
```
Crea un entorno virtual:
```bash
python3 -m venv venv  
source venv/bin/activate
```
Instala las dependencias:
```bash
pip install -r requirements.txt
```
Ejecuta la aplicación:
```bash
python3 main.py
```

## 🚀 Uso
🟢 Abre la aplicación con el comando anterior.

➕ Añade las aplicaciones que deseas rastrear desde la interfaz gráfica.

📉 Minimiza o cierra la aplicación para que siga rastreando en segundo plano.

📂 Consulta el tiempo de uso registrado en la base de datos.

## 🛠️ Tecnologías utilizadas
Python 🐍: Lenguaje principal del proyecto.

psutil ⚙️: Para rastrear procesos del sistema.

Process 🔄: Para la gestión de procesos del sistema.

SQLite 🗄️: Almacenamiento de datos.

Tkinter 🎨: Interfaz gráfica.
